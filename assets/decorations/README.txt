Lalitha Shree's Academy — Decoration Pictures

These are lightweight transparent SVG doodles for the website.
Put this entire "decorations" folder inside your website's "assets" folder:

assets/
  decorations/
    pencil.svg
    pen.svg
    ...

The filenames match the decoration paths used in the side-decoration HTML.

If your code currently says .png, change the extension to .svg, e.g.
assets/decorations/pencil.svg

No JavaScript is required for these decorations.
